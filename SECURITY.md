# Security Policy

quay-term handles SSH credentials and keys, so security reports are taken seriously.

## Supported versions

The project is pre-release. Only the latest `main` and the latest tagged release receive fixes.

## Reporting a vulnerability

**Do not open a public issue.** Use GitHub's private reporting:

https://github.com/bhali16/quay-term/security/advisories/new

Please include the affected version or commit, steps to reproduce, and the impact. You can expect an acknowledgement within a few days. Please allow time for a fix before public disclosure.
