# Clean-Room Policy

quay-term must not copy protected expression from MobaXterm or any other product.

## Rules

1. Work only from **public** sources: product marketing pages, public documentation, user-visible behavior, and open standards (SSH RFCs 4250-4254, the SFTP draft, xterm control sequences, ECMA-48).
2. **Never** decompile, disassemble, or inspect the binaries, resources or network traffic of other products.
3. Do not copy icons, images, strings, layouts, sounds, or documentation text.
4. Do not use confusingly similar names or branding.
5. Features (ideas and functions) may be reimplemented. Expression may not. Write your own spec first, then implement from it.
6. Third-party dependencies must have GPL-3.0-compatible licenses.
7. Do not paste code from other projects unless its license is compatible and you credit it.

## For contributors

By opening a pull request you confirm that your contribution follows these rules. If you have worked on a similar proprietary product and are unsure, ask in the pull request before contributing.
